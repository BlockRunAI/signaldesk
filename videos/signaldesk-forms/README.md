```sh
npm run check
npm run dev
npm run render -- --quality delivery --output renders/signaldesk-demo.mp4
```

it does not call X, Jev or BlockRun. Chinese typography uses the host system
font (created on macOS); the bundled JetBrains Mono font is licensed under OFL.
